# Промпты

Собираются на клиенте. Enhance (если задан `OPENROUTER_TEXT_MODEL`) — на сервере; при фейле остаётся сырой текст.

## Герб

[`src/data/crestData.js`](../src/data/crestData.js) → `buildOpenRoadCrestPrompt({ animal, nationality, element, motto, shieldStyle })`.

Плоский этнографический folk, не европейская геральдика. Пустой девиз подменяется девизом стихии.

| Параметр | Опции |
|---|---|
| Тотем | медведь, волк, орёл, лис, рысь, лось, сокол, сова, олень, бобр |
| Народность | русские, татары, удмурты, башкиры, марийцы, коми, чуваши |
| Стихия | огонь, вода, земля, воздух |
| Щит | варяжский (`classic`), прямоугольный (`french`), славянский, каплевидный (`spanish`), круглый тарч (`targe`) |

Блоки промпта: фигура животного (главный объект щита) → орнамент народности → стихия → палитра → геометрия щита и лента девиза `«…»` → visual style + negatives (нет фотореализма, имперского орла, 3D, металлического золота).

## Орнамент

[`src/data/ornamentData.js`](../src/data/ornamentData.js) → `buildOpenRoadOrnamentPrompt({ symbols, composition })`.

Плоский 2D-вектор. Палитра: охра `#C88A35` / белый / тёмно-зелёный `#1C4524` / бордовый `#7A1C2C`.

Порядок блоков (композиция **раньше** символов и стиля):

1. `COMPOSITION TYPE`
2. Пространственная геометрия холста
3. Выбранные символы + иерархия
4. Стиль Прикамья + палитра
5. Visual style + Avoid + негатив конкретной композиции

| Композиция | Холст | Пустое |
|---|---|---|
| Плитка (`tile`) | 95–100%, бесшовный раппорт | нет |
| Лента (`border`) | полоса 20–30% высоты | много сверху/снизу |
| Медальон (`medallion`) | 60–70% | ≥15% вокруг |
| Рамка (`frame`) | 15–25% по краям | 65–75% центра пусто |

Символы: ромб, волна/река, солнечный крест, елочка/папас, двойной ромб (шудо). Минимум один.

Спека по композициям: [Требования к промптам для композиций орнамента](Требования%20к%20промптам%20для%20композиций%20орнамента.md).
