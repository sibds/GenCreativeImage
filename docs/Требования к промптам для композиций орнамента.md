Ниже — требования, которые стоит зашить в промпты для каждой из существующих композиций приложения. Главная задача — чтобы модель понимала не только стиль орнамента, но и **геометрию размещения узора на холсте**.

## Общие требования для всех композиций

Во всех промптах желательно явно задавать:

- тип композиции;
- положение орнамента на холсте;
- долю холста, которую он занимает;
- допустимость или запрет повторения;
- наличие или отсутствие пустого пространства;
- направление орнамента;
- наличие рамки;
- требование к симметрии;
- запрет на смешение разных типов композиции.

Общий блок:

```text
Flat 2D vector ornament.
Crisp geometric contours.
Simple closed shapes.
Clear visual hierarchy.
Balanced negative space.
Traditional Kama-region inspired ornament.

Use only the specified symbols and colors.

No gradients.
No shadows.
No 3D.
No photorealism.
No people.
No animals unless explicitly selected as a symbol.
No text.
No random decorative elements outside the selected composition.
```

# 1. Сплошное полотно / Плитка

### Что должна получить модель

Равномерный повторяющийся орнамент, заполняющий весь холст без выраженного центра.

### Требования к промпту

Обязательно указать:

- бесшовный или визуально непрерывный повтор;
- отсутствие центральной доминанты;
- равномерную плотность узора;
- одинаковый масштаб элементов;
- заполнение всего холста;
- повтор по горизонтали и вертикали;
- отсутствие медальона и отдельной рамки.

### Рекомендуемый блок

```text
COMPOSITION TYPE: ALL-OVER REPEATING ORNAMENT.

Create a continuous geometric ornament covering the entire square canvas.

The pattern must repeat evenly in both horizontal and vertical directions.
Maintain uniform density and scale across the whole image.

There must be no dominant central symbol and no isolated focal point.

Selected symbols should become repeating modules of the pattern.

The ornament should visually continue beyond all four canvas edges.

NO central medallion.
NO isolated emblem.
NO decorative frame.
NO large empty areas.
NO single oversized symbol.
```

### Если нужна именно бесшовная текстура

Добавить:

```text
Create a seamless tileable pattern.
Left and right edges must connect visually.
Top and bottom edges must connect visually.
```

# 2. Ленточный каймовый узор

### Что должна получить модель

Узкая горизонтальная декоративная полоса, а не заполненный узором холст.

### Требования к промпту

Обязательно указать:

- одна горизонтальная полоса;
- расположение по центру холста;
- большая пустая область сверху и снизу;
- повтор элементов только по горизонтали;
- фиксированная высота полосы;
- отсутствие вертикального расширения;
- отсутствие рамки вокруг всего изображения.

### Рекомендуемый блок

```text
COMPOSITION TYPE: HORIZONTAL ORNAMENTAL BORDER.

Create one long horizontal decorative ornament band centered on the canvas.

The band should occupy approximately 20–30% of the image height and 80–90% of its width.

Leave large empty areas above and below the ornament.

The selected symbols should repeat rhythmically from left to right.

Maintain a consistent band height.

The ornament must read as a decorative border or embroidered ribbon.

NO full-canvas pattern.
NO vertical repetition.
NO central medallion.
NO rectangular frame surrounding the image.
NO ornament filling the background.
```

### Для более традиционного вида

Можно добавить:

```text
Use a clear upper and lower boundary line within the ornamental band.
Keep the rhythm continuous and symmetrical along the horizontal axis.
```

# 3. Центральная розетка / Медальон

### Что должна получить модель

Один отдельный компактный орнаментальный объект в центре.

### Требования к промпту

Обязательно указать:

- ровно один медальон;
- выраженную внешнюю границу;
- компактную форму;
- 60–70% размера холста;
- минимум 15% пустого пространства вокруг;
- радиальную или четырёхстороннюю симметрию;
- отсутствие окружающей рамки;
- отсутствие повторяющегося фона.

### Рекомендуемый блок

```text
COMPOSITION TYPE: ISOLATED CENTRAL MEDALLION.

Create exactly ONE self-contained ornamental medallion centered on the square canvas.

The medallion should occupy approximately 60–70% of the canvas.

Leave at least 15% clean empty space around it on every side.

Use a compact circular, octagonal, diamond-shaped or rosette-like silhouette.

Arrange selected symbols around one central focal point.

Use strict radial or four-way symmetry.

The ornament must have a clearly visible outer silhouette and read as one independent emblem.

NO full-page ornament.
NO repeating background.
NO carpet pattern.
NO textile panel.
NO rectangular frame.
NO ornament touching the canvas edges.
NO multiple medallions.
```

# 4. Рамка с узорным углом

### Что должна получить модель

Преимущественно пустой центр и декоративная рамка по периметру, особенно выразительная в углах.

### Требования к промпту

Обязательно указать:

- пустой центральный участок;
- орнамент только по краям;
- четыре угла;
- повтор вдоль сторон;
- угловые элементы крупнее или сложнее;
- центральная область без узора;
- отсутствие медальона в центре.

### Рекомендуемый блок

```text
COMPOSITION TYPE: ORNAMENTAL FRAME WITH DECORATED CORNERS.

Create a decorative geometric frame around the perimeter of the square canvas.

Keep the central 65–75% of the image completely empty and visually calm.

Place the main ornamental motifs in the four corners.

Connect the corner motifs with restrained repeating border elements along the four sides.

The corners should be visually stronger and more detailed than the side borders.

Maintain perfect symmetry between opposite corners and sides.

NO central ornament.
NO central medallion.
NO full-canvas pattern.
NO decorative elements inside the central empty area.
NO carpet-like filling.
```

### Для более лёгкой рамки

Добавить:

```text
Keep the side borders thin and restrained.
Use the selected symbols primarily in the corner ornaments.
```

# Дополнительные системные требования

Чтобы композиции не смешивались между собой, для каждой настройки желательно добавлять явный негативный блок.

Например:

### Для плитки

```text
Do not interpret this as a medallion, border or frame.
```

### Для ленты

```text
Do not expand the ornament vertically or turn it into a full-page pattern.
```

### Для медальона

```text
Do not create a surrounding border or repeating background.
```

### Для рамки

```text
Do not place a dominant symbol in the center.
```

# Иерархия промпта

Лучше формировать итоговый промпт в таком порядке:

```text
1. COMPOSITION TYPE
2. Exact spatial layout
3. Selected symbols
4. Rules for symbol hierarchy
5. Cultural / regional style
6. Color palette
7. Graphic style
8. Negative constraints
```

Композицию лучше ставить **раньше описания символов и художественного стиля**.

То есть не:

```text
Traditional ornament with rhombuses, crosses, detailed patterns...
Create a central medallion...
```

а:

```text
Create exactly ONE isolated central medallion...
Inside it integrate the following symbols...
Style: traditional Kama-region ornament...
```

# Требования к масштабу для каждой композиции

| Композиция | Заполнение холста | Пустое пространство |
|---|---:|---:|
| Сплошное полотно | 95–100% | практически отсутствует |
| Ленточный узор | 20–30% по высоте | много сверху и снизу |
| Медальон | 60–70% | минимум 15% вокруг |
| Рамка | 15–25% по краям | 65–75% центра пусто |

# Правило для выбранных символов

Сейчас есть риск, что модель воспринимает каждый выбранный символ как обязательный крупный самостоятельный элемент. Лучше передавать отдельное правило:

```text
Integrate the selected symbols into the composition rather than placing each of them as a separate standalone icon.

Establish a hierarchy:
one symbol may serve as the dominant motif,
while the others should act as secondary supporting motifs.

Do not repeat every selected symbol excessively.
```

Для плитки это правило можно изменить:

```text
Transform the selected symbols into repeatable ornamental modules.
```

Для ленточного узора:

```text
Arrange the selected symbols into a rhythmic horizontal sequence.
```

Для медальона:

```text
Arrange the selected symbols hierarchically around a single central focal point.
```

Для рамки:

```text
Use selected symbols primarily in corners and secondary border modules.
```

# Что желательно убрать из текущих промптов

Не стоит использовать без необходимости:

```text
high detail
intricate patterns
8k resolution
masterpiece
extremely detailed
complex ethnic pattern
```

Эти слова часто заставляют модель **дозаполнять пустое пространство дополнительным орнаментом**.

Лучше:

```text
controlled detail
clear geometry
simple closed shapes
balanced negative space
strong visual hierarchy
```

Главное правило для генератора: **композиция должна описываться не одним названием, а отдельным блоком пространственных ограничений**. Именно он должен меняться при выборе «Плитка / Лента / Медальон / Рамка».
