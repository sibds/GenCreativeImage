# Киоск

Полноэкранный режим под Chrome `--kiosk`: без навбара и футера, контент вписывается в экран (`useKioskFit` ставит CSS `zoom`), из приложения **нельзя** вернуться на лаунчер. Промпт после генерации не показывается.

Конфиг: [`src/kiosk/config.js`](../src/kiosk/config.js).

## Переменные

| Переменная | Default | Поведение |
|---|---|---|
| `VITE_KIOSK_CONTROLS` | `0` | `1` — в Navbar кнопка «Киоск», в шапке киоска «Обычный режим». Иначе кнопок входа/выхода нет |
| `VITE_KIOSK` | `0` | `1` — открыть сразу в киоске (киоск-ПК). Иначе обычный UI |
| `VITE_KIOSK_IDLE_MS` | `600000` | после успешной генерации под картинкой сразу идёт отсчёт (10 мин). Любой клик/тач/клавиша перезапускает. `0` на таймере — сброс **состояния текущего приложения** (форма и картинка), URL и экран не меняются |
| `VITE_KIOSK_COUNTDOWN_MS` | `30000` | когда осталось ≤ 30 с, кнопка «Сброс» становится бордовой |

`VITE_KIOSK_*` попадают в клиентский бандл — это не секреты. После смены перезапусти Vite / пересобери.

## Приоритет включения

1. `VITE_KIOSK` (старт).
2. `sessionStorage['kiosk']` (`1` / `0`) — если есть.
3. `?kiosk=1` в URL **побеждает** и env, и storage.

`persistKiosk(on)` пишет sessionStorage и `history.replaceState` (добавляет/снимает `?kiosk=1`).

Вход без кнопок: `?kiosk=1`. Ярлык Chrome:

```bash
chrome.exe --kiosk --app=http://localhost:5173/?kiosk=1
```

## Сброс

- Ручной: кнопка «Сброс» / «Сброс через M:SS» → подтверждение «Сбросить?».
- Авто: idle-таймер после картинки ([`useKioskIdle.js`](../src/kiosk/useKioskIdle.js)). Слушает `pointerdown`, `keydown`, `touchstart`.
- `handleReset` в App инкрементирует `session` → генераторы ремаунтятся через `key`. Лаунчер не открывается.

В обычном режиме та же кнопка «Сброс» есть на карточке результата, но без отсчёта.
